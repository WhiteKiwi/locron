## Whole-record syntax

All quoted spaces below are exactly one ASCII space. A diagnostic record is complete only with its terminal LF. For these direct Rust-written files, no CR/CRLF conversion, ANSI stripping, leading-prefix removal, whitespace normalization or incomplete-tail salvage is proposed. If an instrumented child actually emits another framing, report it unrecognized and amend the plan before accepting it.

```
record = nonconfig-prefix returned LF
       | config-prefix returned full-config LF
       | config-prefix returned fallback-config LF

prefix = "windows-store-open operation=" u64 " stage=" stage
nonconfig-prefix = prefix with a nonconfiguration stage
config-prefix = prefix with sqlite-configure-wal|sqlite-configure-settings

returned = " category=store"
         | " category=io kind=" io-kind " raw_os=" raw-option
         | " category=sqlite"
         | " category=sqlite primary=" sqlite-primary " extended=" i32

raw-option = "None" | "Some(" i32 ")"

full-config = " pid=" u32
              " gate=" (gate|"unobserved")
              " phase=" phase
              " attempts=" u64
              " entry_rem_us=" u64
              " phase_us=" u64
              " gate_us=" optional-u64
              " remaining_us=" optional-u64
              " autocommit=" optional-bool
              " mode=" mode
              " done=" optional-bool
              " observed_primary=" optional-u8-decimal
              " observed_extended=" optional-i32
              " prepare_us=" optional-u64 "," optional-u64
              " query_us=" optional-u64 "," optional-u64
              " row_us=" optional-u64 "," optional-u64
              " finalize_us=" optional-u64 "," optional-u64

fallback-config = " pid=" u32 " configuration=unobserved"
optional-u64 = u64|"unobserved"
optional-i32 = i32|"unobserved"
optional-u8-decimal = decimal0..255|"unobserved"
optional-bool = "true"|"false"|"unobserved"
```

Unsigned values are canonical decimal0 or a nonzero leading digit followed by digits, range0..2^64-1 or0..2^32-1 respectively. Signed i32 is canonical0, positive decimal without plus/leading zeros, or a minus followed by a nonzero decimal magnitude, range-2147483648..2147483647. Reject -0, plus signs, signs on unsigned values, overflows, tabs, duplicate/unknown/reordered/missing keys, any extra suffix and any incomplete pair. `raw_os=None` is an actual returned absence, not the Snapshot sentinel `unobserved`.

A timestamp may exceed an operational allowance when a synchronous call returned late; decoder values do not prove preemption or completion within a budget. PID and operation are validated and discarded, never printed or treated as identity authority.

A full configuration body must be <=768 bytes, excluding its final LF. The producer itself falls back atomically to the complete original-returned prefix, PID and `configuration=unobserved` if larger; accept exactly that fallback, never a prefix of a full tail.
